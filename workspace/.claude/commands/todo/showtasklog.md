# Show Task Log

When invoked:
1. Check the `todo.txt` file and `tasks/task-log.jsonl` file in the workspace root.
2. Read and display the pending tasks and recently completed tasks in a clean, readable summary list.
3. If no tasks exist, reply with "No tasks logged yet! Use `/addtask` to create one."
4. Keep the output clean and concise (avoid dumping raw JSON unless specifically asked).
